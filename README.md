# LLM-Simulated Investor Sentiment and Sports Event-Driven Stock Returns
### *Can synthetic fan/investor personas predict abnormal returns following Manchester United match outcomes?*

---

## Overview

This project simulates how Manchester United match results affect **MANU stock price** on the next trading day by deploying large language model (LLM)-based investor persona agents. The core research question is:

> **Can simulated fan/investor sentiment — generated by LLM personas — predict out-of-sample (OOS) stock price movements?**

The pipeline generates 200 heterogeneous investor personas, exposes each persona to a match event summary, collects structured trading reactions (BUY / HOLD / SELL), aggregates them into sentiment features per match, and evaluates whether those features improve stock return prediction beyond a market-only baseline.

This work is grounded in the sports finance and behavioral finance literature (Edmans et al., 2007; Bernile & Lyandres, 2011; Baker & Wurgler, 2006) and contributes a novel LLM-based methodology for generating synthetic investor sentiment at scale.

## Pipeline Architecture

```
Step 1: Persona Generation   →  200 agents × 4 fan types
Step 2: Reaction Simulation  →  200 agents × 190 matches = 38,000 LLM calls
Step 3: Feature Aggregation  →  Per-match sentiment features (buy/sell pressure, net demand)
Step 4: Model Validation     →  Rolling-origin OOS regression (Ridge)
Step 5: Market Comparison    →  Backtest vs. realized MANU returns
```

## Persona Design

Personas are generated using **Latin Hypercube Sampling** to guarantee coverage across the trait space. Each persona is assigned a type according to the literature-backed distribution below:

| Persona Type    | Share | Description |
|-----------------|-------|-------------|
| `TEMPORARY_FAN` | 45%   | Casual followers; low loyalty, high emotional variance |
| `FANATICAL_FAN` | 25%   | Deep club loyalty; strong emotional reaction to results |
| `LOCAL_FAN`     | 15%   | UK/EU-based; proximity increases information sensitivity |
| `INVESTOR_FAN`  | 15%   | Finance-oriented; trades on fundamental + sentiment signals |

Each persona carries continuous traits (`fan_loyalty`, `risk_tolerance`, `investment_horizon`, `market_sophistication`) and a region assignment (US-heavy, reflecting MANU's shareholder base; YouGov, 2022).

**Sample persona record:**
```json
{
  "persona_id": "p_0042",
  "persona_type": "INVESTOR_FAN",
  "region": "US",
  "fan_loyalty": 0.71,
  "risk_tolerance": 0.58,
  "investment_horizon": "medium",
  "market_sophistication": 0.84
}
```

## Match Event Encoding

Each match is encoded into a structured event object containing:
- **Outcome**: win / draw / loss, goal differential
- **Surprise score**: derived from pre-match betting odds (implied probability → realized outcome surprise)
- **Opponent strength**: normalized ELO-style rating
- **Match importance**: competition tier weighting
- **Market context**: prior 5-day MANU return, 20-day volatility, market index return

**Surprise** is the primary behavioral trigger: a win against a heavy favorite is a small surprise; a loss to a heavy underdog is a large negative shock.

---

## Reaction Generation

Each persona responds to a match event via a structured LLM prompt (Ollama / `llama3.1`). The model returns a JSON object:

```json
{
  "action": "BUY",
  "size_0_1": 0.62,
  "horizon": "short",
  "confidence_0_1": 0.74,
  "signals": ["positive_result", "surprise_win"],
  "emotion": "excited",
  "rationale_short": "Unexpected win over Arsenal; upgrading short-term outlook."
}
```

Key design decisions:
- **Temperature 0.6** for reaction sampling (prevents action collapse to HOLD while keeping JSON validity)
- **Parallel execution** via `ThreadPoolExecutor` with `N_WORKERS=2` and `OLLAMA_NUM_PARALLEL=2` for local stability
- **Checkpoint/resume** via `reactions.jsonl` append mode — crash-safe across 38,000 calls

## Feature Engineering

Per-match features are aggregated from the full 200-agent panel:

| Feature | Description |
|---------|-------------|
| `mean_net_demand` | Average (buy − sell) across all agents |
| `buy_share` / `sell_share` / `trade_share` | Fraction of agents taking each action |
| `mean_size_trade` | Average position size (0–1 scale) |
| `liq_weighted_pressure` | Net demand weighted by agent liquidity sensitivity |

All features are computed **globally** and **per persona type** (e.g., `mean_net_demand__fanatical_fan`), yielding 36 LLM-derived features alongside 9 baseline market/match features (44 total).

## Model & Evaluation

**Method:** Ridge regression with rolling-origin (expanding window) out-of-sample evaluation.

- **Baseline model**: match + market features only (9 features)
- **Augmented model**: baseline + all LLM sentiment features (44 features)
- **Target variable (`y`)**: MANU abnormal return on day *t+1* (next trading day after match)
- **Training window**: `min_train = 114` | **OOS evaluation**: 76 matches

### Results

| Model | RMSE | MAE | Hit Rate | OOS R² | n_test |
|-------|------|-----|----------|--------|--------|
| Baseline | 0.0266 | 0.0166 | **63.2%** | **0.102** | 76 |
| Augmented (+ LLM) | 0.0292 | 0.0175 | **65.8%** | −0.079 | 76 |
| Delta (Aug − Base) | +0.003 | +0.001 | +2.6pp | −0.181 | — |

**Key findings:**
- The **baseline model achieves a positive OOS R² of 10.2%**, indicating that match surprise and market context carry genuine predictive signal for next-day MANU returns.
- The **LLM-augmented model improves directional accuracy (hit rate: +2.6pp)** but reduces point-forecast precision (higher RMSE), consistent with sentiment features adding noise alongside signal.
- The delta suggests LLM features carry **incremental directional information** not captured by the baseline, while point estimates remain noisy — a pattern consistent with behavioral finance literature on sentiment indicators.

## Cross-Validation: Split Ratio Experiment

To assess model robustness, we varied the train/test split ratio from 50%/50% to 80%/20% using a rolling-origin expanding window (`cv_split_experiment.py`). All models use Ridge regression (α = 1.0).

### R² OOS by Split Ratio

| Train % | OOS n | Baseline R² | Augmented R² |
|---------|-------|-------------|--------------|
| 50% | 94 | +0.0900 | +0.0384 |
| 55% | 85 | +0.1039 | +0.0188 |
| 60% | 75 | +0.1374 | +0.0638 |
| 65% | 66 | +0.1862 | +0.0572 |
| 70% | 56 | +0.2628 | +0.2003 |
| 75% | 47 | +0.1613 | +0.1530 |
| 80% | 37 | +0.2580 | **+0.2912** |

### Hit Rate by Split Ratio

| Train % | OOS n | Baseline | Augmented | Δ |
|---------|-------|----------|-----------|---|
| 50% | 94 | 62.8% | 62.8% | 0.0pp |
| 55% | 85 | 62.4% | 62.4% | 0.0pp |
| 60% | 75 | 64.0% | 64.0% | 0.0pp |
| 65% | 66 | 65.2% | 65.2% | 0.0pp |
| 70% | 56 | 66.1% | **69.6%** | **+3.5pp** |
| 75% | 47 | 61.7% | **66.0%** | **+4.3pp** |
| 80% | 37 | 56.8% | **64.9%** | **+8.1pp** |

### Key Findings

- **Baseline R² OOS is positive across all split ratios**, confirming that match surprise and market context provide robust predictive signal regardless of evaluation window size.
- **LLM persona features improve directional accuracy when training data is sufficient (train ≥ 70%)**: Augmented outperforms Baseline on hit rate by +3.5pp to +8.1pp in the 70–80% train range.
- At lower train ratios (50–65%), LLM features add noise rather than signal — consistent with the hypothesis that persona features require sufficient historical context to calibrate effectively.
- At 80% train, Augmented achieves the highest overall R² OOS (+0.291), suggesting LLM features also improve magnitude prediction with enough training data.

> **Interpretation**: LLM-simulated investor sentiment provides reliable directional signal once the model has sufficient training matches (≥133). This has practical implications for live deployment timing and minimum data requirements.

## Backtest

`compare_predictions_to_market_v3.py` implements:
- **Long/Cash strategy**: go long on predicted positive returns, hold cash otherwise
- **Long/Short strategy**: go long or short based on prediction sign
- Configurable transaction costs (basis points)
- Calibration tables (predicted quantile vs. realized return)

Run:
```bash
python compare_predictions_to_market_v3.py \
  --features Step3_MatchFeatures.xlsx \
  --preds Step3_Predictions.xlsx \
  --pred_cols y_hat_baseline,y_hat_augmented \
  --fee_bps 5 \
  --out Compare_Results.xlsx
```

## Technical Highlights

- **38,000 LLM inference calls** executed locally via Ollama with full checkpoint/resume support
- **Latin Hypercube Sampling** for persona diversity guarantee across high-dimensional trait space
- **Structured JSON schema enforcement** for LLM outputs (format_schema + fallback reconciliation)
- **Rolling-origin evaluation** — no look-ahead bias in OOS metrics
- **Modular step control** (`SKIP_TO_STEP`) enabling partial reruns without restarting from scratch
